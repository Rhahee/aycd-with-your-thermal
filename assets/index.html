BLUETOOTH SERIAL

Pengaturan printer

ESC/POS

Pasangkan printer melalui pengaturan Bluetooth Windows, lalu pilih port COM keluar milik printer. Jika ada beberapa perangkat, cocokkan alamat Bluetooth di pengaturan Windows dengan halaman self-test printer.

Umumnya 576 dot untuk 80 mm atau 384 dot untuk 58 mm. Ubah bila tepi cetakan terpotong.
COM6 berhasil mencetak pada 115200. Angka BT Baud 460800 di self-test printer berbeda dari batas port Windows.

Pesan “data terkirim” berarti komputer berhasil menulis ke port; periksa kertas untuk memastikan printer benar-benar mencetak.
