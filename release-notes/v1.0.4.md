## Perubahan

- Installer Windows siap pakai untuk pemasangan tanpa SDK .NET atau Git.
- Tombol Update kini mengunduh paket aplikasi siap pakai dari GitHub Releases, memeriksa checksum SHA-256, lalu membuka ulang aplikasi. SDK .NET tidak lagi diperlukan untuk memperbarui aplikasi.
- Data daftar dan profil printer tetap berada di folder data lokal saat aplikasi diperbarui atau dipasang ulang.

Unduh berkas `.exe` di Assets untuk pemasangan baru. Tombol Update di dalam aplikasi menggunakan berkas `.zip` secara otomatis.
