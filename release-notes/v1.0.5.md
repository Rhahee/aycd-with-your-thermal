## Perubahan

- Ikon aplikasi, installer, dan taskbar memakai simbol printer AYCD.
- Tombol **Perbarui** pada pratinjau dihapus karena pratinjau sudah berubah otomatis saat daftar diedit.
- Paket installer dan update tetap tersedia untuk Windows x64; tombol Update menggunakan paket `.zip` secara otomatis.

Unduh berkas `.exe` di Assets untuk pemasangan baru.
